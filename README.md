# Amizax Backend

Backend API for a cryptocurrency exchange platform built with Django and Django REST Framework.

## Overview

Amizax is a cryptocurrency exchange platform developed to manage users, authentication, wallets, transactions, and exchange-related operations through a secure REST API architecture.

The platform was designed as a real-world freelance project and includes account management, wallet services, exchange functionality, and administrative tools.

## Features

- User registration and authentication
- JWT-based authorization
- OTP verification system
- Wallet management
- Cryptocurrency exchange operations
- Transaction management
- Chat and support system
- Administrative dashboard
- RESTful API architecture
- Role and permission management

## Tech Stack

### Backend
